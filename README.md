# Decoy Documents: Preventing Intellectual Property Theft Using Machine Learning

## Overview

Decoy Documents is a Machine Learning-based web application developed to protect sensitive Intellectual Property (IP) documents from unauthorized access and data theft. The system generates and manages decoy documents that closely resemble genuine files, making it difficult for attackers to identify valuable information through document clustering and topic modeling techniques. By introducing deceptive content, the application strengthens document security and minimizes the risk of confidential information being exposed.

---

## Problem Statement

Organizations increasingly face Intellectual Property (IP) theft, where attackers employ machine learning techniques such as document clustering and topic modeling to analyze stolen documents and extract confidential information. Traditional security mechanisms, including encryption, firewalls, and access control, often fail to prevent attackers from gaining meaningful insights once documents have been exfiltrated.

This project addresses the challenge by introducing decoy documents that mislead attackers, protect sensitive information, and enhance the overall security of organizational data.

---

## Objectives

- Protect sensitive Intellectual Property (IP) documents from unauthorized access.
- Generate realistic decoy documents to mislead attackers.
- Reduce the effectiveness of document clustering and topic modeling attacks.
- Strengthen document security using deception-based techniques.
- Improve protection of confidential organizational information.
